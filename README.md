# Craps Dice Game

Play the classic casino game "Craps" with this Python program! Roll two dice and try to win by following the rules of the game.

## How to Play

1. Run `project2.py`.  
2. The program will roll two dice automatically and show the sum.  
3. On the first roll:
   - If the sum is 7 or 11 → you win immediately.  
   - If the sum is 2, 3, or 12 → casino wins immediately.  
   - If the sum is 4, 5, 6, 8, 9, or 10 → this becomes your **goal number**.
4. Keep rolling the dice:
   - If you roll the goal number again → you win.  
   - If you roll 7 before the goal number → you lose.  

## Requirements

- Python 3.x
